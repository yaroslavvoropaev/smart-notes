# Smart Notes — краткое техническое задание

## 1. Идея проекта

**Smart Notes** — веб-приложение для хранения учебных материалов и быстрого поиска информации внутри них.

Пользователь загружает лекции, конспекты и другие документы, объединяет их в коллекции по предметам или темам и затем ищет нужную информацию сразу по содержимому всех загруженных файлов.

## 2. Какую проблему решает

В процессе учебы накапливается много PDF-файлов, текстовых конспектов и других материалов. Они хранятся в разных папках, и при необходимости вспомнить конкретную тему приходится вручную открывать документы и искать внутри каждого из них.

Smart Notes позволяет хранить эти материалы в одном месте и находить нужные фрагменты текста через единую поисковую строку. Это сокращает время на поиск уже изученной информации.

## 3. Функциональность MVP

- **Загрузка документов.** Поддержка PDF, DOCX, TXT и Markdown (MD).
- **Хранение материалов.** Просмотр списка загруженных документов, открытие или скачивание оригинального файла, удаление документов.
- **Коллекции.** Группировка материалов по предметам или темам (например, Java, DevOps, математика).
- **Автоматическая обработка.** Извлечение текста из загруженных документов и подготовка его к поиску.
- **Поиск по содержимому.** Единый поиск по тексту документов, а не только по названиям файлов.
- **Результаты поиска.** Отображение названия документа, подходящего фрагмента текста и номера страницы для PDF, если эту информацию удалось извлечь.
- **Фильтрация.** Возможность искать во всех материалах или только внутри выбранной коллекции.
- **Веб-интерфейс.** Простые страницы для загрузки, организации и поиска материалов.

## 4. Что не входит в MVP

- Семантический поиск с использованием ИИ и ответы на вопросы по документам.
- Распознавание текста на сканах и изображениях (OCR).
- Совместная работа нескольких пользователей, регистрация и сложная система прав доступа.

## 5. Стек технологий

| Область | Технологии |
|---|---|
| Язык программирования | Java 21+ |
| Backend | Spring Boot, Spring Web, Spring Data JPA |
| База данных | PostgreSQL |
| Миграции БД | Flyway |
| Извлечение текста | Apache PDFBox (PDF), Apache POI (DOCX), стандартные средства Java (TXT/MD) |
| Поиск | PostgreSQL Full Text Search |
| Frontend | HTML, CSS, JavaScript (при необходимости — Thymeleaf) |
| Тестирование | JUnit 5, Spring Boot Test |
| Запуск | Docker, Docker Compose |

## 6. Подход к разработке

Проект разрабатывается как веб-сервис с основным акцентом на **самостоятельную backend-разработку на Java и Spring Boot**: работу с документами, хранение данных, обработку текста и поиск.

**Фронтенд будет писаться с помощью ИИ.** Его задача — предоставить удобный интерфейс для работы с возможностями backend; глубокая самостоятельная frontend-разработка не является целью проекта.

## 7. Ожидаемый результат

Пользователь может загрузить набор учебных материалов, разложить их по коллекциям, ввести поисковый запрос, увидеть подходящие фрагменты из разных документов и открыть нужный оригинал.

**Основной сценарий:** загрузить документ → система извлекает его текст → пользователь ищет по всем материалам → получает подходящие результаты.
